# Nietzsche 8-bit — GitHub Pages

Jogo simples em um único `index.html`, sem dependências externas.

## Publicar no GitHub Pages
1. Crie um repositório no GitHub.
2. Envie `index.html` para a raiz do repositório.
3. Vá em **Settings → Pages**.
4. Em **Build and deployment**, selecione **Deploy from a branch**.
5. Escolha a branch `main` e a pasta `/ (root)`.
6. Salve. O GitHub fornecerá o endereço da página.

## Controles
- Setas ou A/D: movimentação.
- Espaço/Enter: avançar.
- 1–4: respostas de múltipla escolha.
- Na forca: digite as letras e pressione Enter.
- 3 vidas; cada erro nas questões de múltipla escolha tira 1 vida.
- Na forca, 3 erros também fazem perder 1 vida.
- Ao terminar, o jogo retorna obrigatoriamente ao começo.
- O áudio é sintetizado no navegador, portanto não há arquivos de som externos.
